Развёрнута 20 сентября 2026 по запросу пользователя. Это доступная по сети административная версия прототипа; реальные покупательские заказы, iikoCard и эквайринг ещё не готовы.

## Службы и данные

- `unagi.service`: Node.js 24.21.0 из `/opt/unagi-node/bin/node`, пользователь ОС `unagi`, один процесс API/worker. Автозапуск включён, перезапуск при ошибке. Сам backend слушает только `127.0.0.1:4300`.
- PostgreSQL: база и ограниченная роль `unagi`, порт 5432 только loopback. Данные находятся в штатном каталоге PostgreSQL, не в локальном PGlite.
- `.env` — `/home/unagi_app/backend/.env`, владелец root, группа unagi, права 640. Содержит серверный ключ шифрования и пароль базы; не выводить и не включать в архив исходников.
- nginx: `/etc/nginx/sites-available/unagi`, HTTPS 443 → loopback backend. HTTP 80 перенаправляет на HTTPS, кроме ACME challenge. X-Forwarded-For заменяется адресом клиента; приложение доверяет только loopback-прокси.
- Сертификат: `/etc/letsencrypt/live/unagi-ip/`, Certbot `/opt/unagi-certbot/bin/certbot`. Короткоживущий сертификат на IP; `unagi-certificate.timer` проверяет продление дважды в сутки, после продления перезагружает конфигурацию nginx.
- Реальные платежи, отправка почты и заказов выключены. Начальные три бренда и меню — примеры.

## Проверка и обслуживание

```sh
systemctl status unagi nginx postgresql
journalctl -u unagi -n 100 --no-pager
curl --fail https://81.200.152.37/health
systemctl restart unagi
systemctl list-timers unagi-certificate.timer
journalctl -u unagi-certificate.service --no-pager
```

Не запускать `npm run setup` на сервере. Одноразовый `scripts/bootstrap-server.js` уже выполнен; повторно создавать пользователей не нужно. При обновлении сохранять `.env`, `.data` и базу. Новые версии проверять до перезапуска; обновления схемы требуют версионированных миграций. Исходники первоначально доставлены архивом, директория сервера не содержит `.git`; простой `git pull` там не работает.

Перед допуском реальных покупателей остаются интеграции, внешнее резервное копирование базы и отдельное сохранение ключа шифрования, проверка восстановления, мониторинг и восстановление доступа/2FA. Автоматические резервные копии в этой установке пока не настроены. Автозапуск проверен по настройкам systemd и перезапуску службы; намеренная перезагрузка всего сервера не проводилась.

Установленное Android-приложение пока офлайн-демо и к этому адресу не подключено. iOS на Windows не проверяется.
