# Платформа: согласованные требования

Источник: ответы владельца проекта в текущей задаче. Разработка разрешена; интеграции включать только после настройки и проверки. Эти требования заменяют раннюю договорённость о постоянном ограничении демоверсией.

- Отдельное приложение каждого бизнеса; внутри выбор его брендов. Единый backend Android/iOS, изоляция независимых бизнесов.
- Первый бизнес UNAGI: 3 точки, разделённые на бренды; внешнее меню iiko на каждый бренд. Настоящие названия/ID ещё не предоставлены.
- Продукт для общепита в России. Цели публикации: App Store, Google Play, RuStore, AppGallery.
- Владелец платформы хочет владеть публикациями. Для Apple это нерешённый вопрос соответствия пункту 4.2.6; публикация не обещана.
- iiko — источник меню, цен, доступности. Настраиваемая передача заказа подтверждённым/неподтверждённым с проверкой поддержки API.
- Настраиваемые доставка, самовывоз, предзаказ, заказ за столом.
- Т-Банк интернет-эквайринг: карты и СБП/QR. Наличные и пользовательские способы оплаты каждого бренда; пользовательское название не создаёт новый банковский API и не подтверждает платёж.
- Получатель денег — соответствующий бизнес; терминалы и соответствия типов оплаты iiko задаются отдельно.
- iikoCard — единственный источник бонусного баланса и расчёта. Приложение показывает и применяет; серверный лимит списания в процентах или бонусах не может превышать разрешённое iikoCard. Собственный бонусный баланс не создавать.
- Промокоды и программа лояльности управляются из кабинета в пределах интеграции; точный способ управления через iikoCard требуется подтвердить на доступах заказчика.
- Авторизация: покупатель вводит свой номер и сам звонит на выданный сервисный номер. Backend проверяет результат у провайдера. Не путать с flash-call от сервиса покупателю. Провайдер пока не выбран; предложен SMS.RU Callcheck, альтернативы REDSMS Wait Call, LoginBot.
- Владелец бизнеса редактирует оформление: цвета отдельных элементов, логотип, блоки. Черновик/публикация/откат.
- Две панели: оператор платформы (клиенты, интеграции, логи, тарифы, ограничения) и бизнес (заказы, меню, настройки, аналитика, сотрудники).
- Внедрение ориентировочно 20 000 ₽ — цена заказчику, не бюджет инфраструктуры. Тариф: подписка либо процент с заказов, с датой вступления и историей.
- Письма об оплате отправляются с почты платформы. Просрочка автоматически ничего не отключает. Вручную оператор может ограничить новые заказы или функции; действующие заказы/возвраты не блокировать.
- Сервер и домен арендует оператор платформы; параметры обещаны, но пока не переданы. iiko оплачивает/предоставляет бизнес; материалы бренда — также бизнес.
- Пользователь просит полный функциональный охват. Не выдавать прототип, тестовый провайдер или неподключённый модуль за готовую рабочую интеграцию.
