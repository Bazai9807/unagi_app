# iOS

Место для будущего Xcode-проекта UNAGI. **iOS-приложение ещё не реализовано.**

Интерфейс и бизнес-логика находятся в `../shared/www/`. Использовать их в WKWebView из bundle; включать ресурсы автоматически при сборке. Не создавать независимую редактируемую копию меню, корзины или UI.

Задание и контекст для реализации на MacBook: [передача проекта](../docs/HANDOFF.md). Общие правила: [AGENTS.md](../AGENTS.md).
