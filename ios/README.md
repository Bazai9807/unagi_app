# UNAGI для iOS

Нативное приложение на SwiftUI, iOS 17+. Откройте `Unagi.xcodeproj` в Xcode и выберите схему `Unagi`. Для запуска на своём iPhone укажите личную Apple Team в Signing & Capabilities и при необходимости измените Bundle Identifier.

Приложение запрашивает конфигурацию, меню и предварительный расчёт у `https://81.200.152.37/api/public/unagi`. Публичный tenant ID указан в `Unagi/APIClient.swift`. Сетевой обмен идёт через URLSession по HTTPS. Демо-корзина, избранное и история тестовых заказов хранятся на устройстве. Личные данные и банковские реквизиты в них не записываются.

Сейчас доступны выбор бренда и точки, категории, поиск, избранное, корзина, выбор способа получения и оплаты, серверный расчёт и локальная история тестовых заказов. Дизайн реализован нативно. Android использует отдельный `shared/www/`; общими остаются backend, каталог и серверные правила. Демо-метаданные Android (описания/аллергены/иллюстрации) пока отсутствуют в публичном API и поэтому не отображаются как проверенные данные в iOS.

**Настоящие заказы недоступны.** `/api/public/:tenant/orders` сейчас отвечает 503; iiko, оплата и вход покупателя ещё не готовы. Кнопки реальной отправки нет. Тестовый заказ только сохраняет локальную запись на iPhone.

После изменения backend разверните его на сервере: мобильный экран расчёта ожидает `paymentMethods` и параметры доставки в `/config`. До развертывания новой версии backend список способов оплаты не появится.

Проверка сборки:

```sh
xcodebuild -project ios/Unagi.xcodeproj -scheme Unagi -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Затем проверьте на симуляторе и телефоне загрузку меню, переключение точки, корзину, предварительный расчёт, историю и сохранение после перезапуска. Для публикации дополнительно нужны App Icon, политика конфиденциальности, реальные данные бизнеса, Apple Team и полный цикл заказов/платежей.
